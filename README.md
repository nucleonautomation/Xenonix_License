**Third-party software retains its own licenses.** Our proprietary terms do not replace or restrict those licenses. The Third_Party directory reproduces upstream notices, including notices for native components inside Python packages. Multiple components may share a single identical text; each text links back to the releases that reference it.

## Find the version you use

Open the [index](Third_Party/README.md), choose a component, then choose its version. The index includes multiple platforms and optional SDK features, so not every listed component is installed together. The installer downloads packages normally; this repository is documentation, not an installation approval system.

The installer **View Licenses** button opens [this repository](https://github.com/nucleonautomation/Xenonix_License). Installed packages retain their upstream license files. A link to this repository does not replace license copies, notices or source-delivery obligations that apply to a particular distribution.

## Corrections and history

For a missing notice or incorrect version entry, open an issue in this repository and identify the component and release. Do not include customer data, activation keys or confidential inspection programs. Preserve published version pages when adding new releases so earlier customers can still find their notices.
